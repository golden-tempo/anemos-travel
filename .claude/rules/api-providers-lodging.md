# Hotel search (two tiers)

- **Hotel search** (`hotel_search_service.go`, `hotel_handler.go`, specs/hotel-search): the `search_hotels` tool and `GET /hotels/search` share ONE implementation, `searchHotels`, which picks between two tiers and reports which one answered. **Rates tier** = SerpApi `engine=google_hotels` (real nightly + total rates for the given dates); **discovery tier** = Google Places `SearchLodging` (`type=lodging`, own `lodging|` cache prefix) with NO prices. The split is forced by the data, not chosen: the rates engine **rejects a dateless query** (`Missing check_in_date`) and Google returns `price_level: null` for every hotel, so neither tier can do the other's job. `HotelSearchResult.RatesLive` is carried **explicitly, never inferred** from "does a stay have a price" — and `summarizeHotels` turns it into words, because a no-rates list looks exactly like a rates list with the numbers omitted and the model will otherwise invent a plausible rate. Prices are stated as **per night for the whole party** (the flight-price-semantics bug, avoided by construction). `price`/`currency` are absent together — no FX exists in this app. The booking handoff is **our** `bookingProvider.SearchURL` (carrying `BOOKING_AFFILIATE_ID`), never SerpApi's `link`, which points at the property's own site and earns nothing. Quota: **own** daily counter (`hotels`) + `SERPAPI_HOTEL_SEARCHES_PER_DAY` so hotels can never starve `search_flights` on the shared 250/month key, a **6 h** cache (vs flights' 15 min — a city+dates rate set is far more re-askable than a fare), and **empty results are deliberately NOT cached**, diverging from the flights service: an empty route is a real answer, an empty city is a bad city string. Exhaustion/outage/no-dates all **degrade, never error**. Rates-tier images are CORS-open googleusercontent URLs used directly; discovery-tier images ride as `photo_ref` through the `/places/photo` billing gate — exactly one of the two is ever set. NOT part of the temporary flights swap: no `Active()` gate, distinct naming, and it must survive `grep serpapiFlights` deletion (it then inherits the whole monthly allowance).
